# Direct viewport tools

The model remains the main editing surface. These tools extend the existing
selection modes and use one compact inspector; desktop controls sit above the
same viewport. View-only inspection never alters saved geometry.

| Tool | Interaction | Feedback and source behavior |
|---|---|---|
| Paint / stamp | Select a brush or library alpha, then draw or tap the model; return to Select to orbit | Millimetre-sized cursor, pressure/depth reading, seam-aware source strokes or a placed alpha layer; one completed gesture is an edit |
| Section | Choose X/Y/Z, drag the plane's handle or enter its offset | Clipped mesh and highlighted triangle/plane intersections; the plane is a view preference |
| Clearance | Toggle envelopes, adjust the requested gap, select a stone | Girdle and pavilion envelopes plus the existing stone report's closest-pair measurements; colours identify crowded settings |
| Mould opening | Build the prepared pattern, then play or scrub withdrawal | Sampled negative cavity surfaces, configured pull/parting, obstruction markers; investment patterns explain that this is a geometric pull study |

Paint refuses the bore and empty space. Moving off the surface ends a stroke
segment instead of joining through the air. Crossing 0/360 degrees takes the
short path across the seam. The source retains normal editable drawings/layers.
Stylus pressure uses the existing Android bridge; a mouse or finger supplies a
stable default pressure. The existing unrolled editor remains available.

Sections derive from the displayed mesh. Cut segments are measurements of that
mesh, not a proof of minimum wall thickness. Clearance envelopes are geometric
inspection aids; quantitative crowding labels use the same model as the stone
report. Mould cavities use the prepared pattern and release-analysis samples;
animation does not certify a manufacturing process or repair an obstruction.

## Layout and appearance

Retain charcoal `#121214`, white `#E9E9EF`, aqua `#2BE2D6`, pink `#FF3D8B`,
amber `#EFB368` and failure red. Use the installed sans at the existing 13-point
body / 11-point hint sizes. Aqua identifies an editable handle, pink the active
ornament, amber cut edges, and red an inspection problem. Tool labels describe
actions; explanations stay next to the relevant field.

```text
Android                              Desktop
ring + cursor / cut / envelopes      viewport tool selector + compact settings
one contextual inspector             large ring + handles / inspection overlay
Shape  Surface  Stones  Casting       existing design and layer panels
```

No extra dashboard, decorative cards or permanent rows are needed. Desktop gains
the same four tools, while mobile exposes each within its existing mode. The
ring's ornament and animated cavity movement carry the visual emphasis.
